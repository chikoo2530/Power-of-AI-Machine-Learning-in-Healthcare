
# MedAI Predict — AI Powered Medical Risk Prediction System

## 📌 Overview
MedAI Predict is an AI & Machine Learning based healthcare web application developed to predict disease risk levels using patient health parameters.

The system currently supports:

- ❤️ Heart Disease Risk Prediction
- 🩸 Diabetes Risk Prediction

This project combines Machine Learning models with a Flask-based web application to provide intelligent prediction, medical history tracking, analytics, notifications, and admin management features.

> ⚠️ This project is developed for learning and research purposes only and is not intended for real-world medical diagnosis.
